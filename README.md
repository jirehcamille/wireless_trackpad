# 🖱️ Windows Trackpad Configuration App

A Windows desktop application designed to provide users with a centralized interface for managing and customizing built-in trackpad settings.

## ✨ Features

- 🏠 *Dashboard* – Provides an overview of the application and trackpad configuration.
- ⚙️ *Trackpad Settings* – Allows users to customize cursor sensitivity, clicking behavior, scrolling, and supported multi-touch gestures.
- 🎨 *Preferences* – Provides application preferences such as appearance and notifications.
- 💾 *Settings Management* – Supports saving, restoring, and resetting configurations.

## 🛠️ Technology Stack

- ⚛️ *Frontend:* React, TypeScript, and Vite
- 🦀 *Backend:* Rust
- 🖥️ *Desktop Framework:* Tauri 2
- 🎨 *UI/UX Design:* Figma
- 💻 *Development Environment:* Visual Studio Code
- 🔧 *Version Control:* Git and GitHub

## 💻 Platform Support

The initial development focuses exclusively on Windows 10 and Windows 11, with priority given to compatible built-in Precision Touchpads.

## 📌 Project Scope

The application aims to provide an alternative interface for managing supported Windows trackpad configurations. Actual functionality will depend on available Windows APIs, hardware compatibility, and operating system limitations.

Support for external wireless trackpads may be considered in a future development phase.

## 🚧 Project Status

Currently in the planning and development preparation stage.
